   # Security policy

   This repository holds the AgroIQ Reference Architecture technical record. To report a security vulnerability in the architecture or in anything the record describes, email cyoncon@metricas.net with "Security" in the subject. Include what you found, how to reproduce it, and the version of the record it concerns.

   Reports are acknowledged within seven days, and confirmed issues are carried in the register of open items of the next version, with credit to the reporter if they wish. Please do not test against any system you do not own or have permission to test.
